# Mercury Power Twin — Support

Mercury Power Twin provides local CAD 2D drawing and conceptual 3D visualization for electrical stations, PV, BESS, data centers, and auxiliary buildings.

## Start

Open a bundled example in Projects. Use Planuri & CAD for 2D drawing and Atelier 3D for conceptual equipment models. Enter dimensions and units explicitly, save the project locally, and use the export controls to share supported outputs.

## File compatibility

Build 9 supports a documented 2D subset of DWG and DXF. DWG import preserves the original source separately; export creates a new R2013 drawing. Unsupported objects, layouts, references, and 3D solids are not a promise of lossless interoperability. Check all import/export notices. Keep the native project format for application-specific equipment and relationships.

PDFs and images are reference documents. Calibration and modeling require confirmed dimensions; the app does not promise arbitrary PDF or Office-to-3D reconstruction.

## Engineering scope

Equipment is conceptual and generic. The app does not provide engineering approval, manufacturer-certified geometry, or automatic TSO/DSO/Grid Code compliance. Verify technical decisions independently.

## Ask for help

Open an issue in this support repository with the app version/build, iOS version, device model, and steps to reproduce. Public issues are visible to others: use a nonconfidential sample when describing a file problem. No sign-in is required in the app itself.

See [PrivacyPolicy.md](PrivacyPolicy.md) for the privacy policy. The newer project-document knowledge update is not included in build 9.
